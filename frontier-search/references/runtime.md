# Claude Code search and fetch behavior

Claude Code specifics for `WebSearch` / `WebFetch`; other runtimes differ. Snapshot verified 2026-10-17 (Claude Code 2.1.302); sources and version qualifiers are in [evidence.md](evidence.md#runtime-facts).

- **Search:** US-only; returns title/URL blocks; may run up to eight backend searches per call. `allowed_domains` and `blocked_domains` cannot be combined in one call. `mode` is required: `standard` (quick, cheap) for probes, lookups, and most gap queries; `extended` ("several times the cost and latency") for a gap ≥4 that `standard` left thin or stale, niche or very recent facts, and `hunt:` freshness queries. Only the tool schema documents `mode`; how it counts against the cap is undocumented.
- **Shared cap:** 200 searches per session by default, subagents included. Since v2.1.290 interactive sessions refill about 100 per hour (`CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR`); `-p` sessions default to no refill, so 200 is hard there. `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` raises the cap; `/clear` resets it unless a workflow survives the clear. A capped call can look like an empty result: follow the cap notice, do not infer thin evidence, and do not raise the limit silently.
- **Extraction:** `WebFetch` returns a small model's answer to your prompt, not the page; before treating silence as evidence, ask a sharper question. It reads up to 100,000 characters per call; since v2.1.290 a longer page reports how much went unread and `offset` reads on. If the section is still missing, `curl` the raw page. Extraction runs at the caller's effort (v2.1.299). The extractor can misattribute detail (such as which release a changelog entry belongs to), so take exact versions, dates, and figures from the raw page.
- **Cache:** 15 minutes per URL by default; a re-fetch inside that window misses recent edits.
- **Redirects:** cross-host redirects are returned, not followed. Fetch the destination, and distinguish a moved source from a dead one.
- **Blocked hosts:** WebFetch checks each hostname against an Anthropic safety blocklist; Reddit has been refused. A refusal is a tool decision, not evidence the site is down. A rate-limited check was misreported as a network or policy block before v2.1.285 and says not to loop since v2.1.286: retry once, then record it. Before v2.1.300, cloud sessions could blame organization policy for a block their own network settings caused. WebFetch sends a `Claude-User` user agent and asks for Markdown; a host that rejects it may still answer `curl`. For APIs and gated venues see [sources.md](sources.md); a decision-relevant claim stays `Access-limited:` until accessible evidence verifies it.
- **Availability:** WebFetch can be switched off (`CLAUDE_CODE_DISABLE_WEB_FETCH`, v2.1.285) or withheld in Team and Enterprise sessions until organization policy loads. WebSearch is unavailable on Amazon Bedrock and Azure-hosted Microsoft Foundry. Report a missing tool as an access limit and use the remaining retrieval route.
